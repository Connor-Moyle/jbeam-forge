# jbeam syntax — as actually shipped (BeamNG.drive 0.39.1)

**Evidence:** `npm run jbeam:corpus` parses every `.jbeam` in every official vehicle zip: **5062 files, 98 MB, 123 zips, 20,352 parts**. Every number below comes from that run on 0.39.1.0 (build 20972).

**Rule:** jbeam is **not JSON** (SPEC §3.4). Every BeamNG text file needs the lenient parser, not just `.jbeam`: `info.json`, `.pc` and `*.materials.json` break JSON rules too (see "Not just .jbeam" below).

## What the lenient parser must accept

| Quirk | Occurrences in corpus | Example / note |
|---|---:|---|
| `//` line and `/* */` block comments | 153,781 | Section markers like `//--HOOD--` inside tables |
| Trailing commas (object, array, **after the root `}`**) | 128,930 | `["h1l", 0.28, -0.92, 0.865],\n]` · files ending in `},` |
| **Missing commas** between object members or array elements | 27,186 | `"scaledragCoef":1\n"variables": [` · rows with no comma between them |
| Stray comma **after the colon** | 62 | `"pickup_frame_crewlongbed_heavy":,\n{` · `"rotators":, [...]` |
| Stray comma **before the colon** | 32 | `"spoke1",: {"links:": …}` (large_tire) |
| Doubled commas (`,,`) | 44 | Empty elements are skipped, not read as null |
| Non-JSON number forms | 98 | Leading zeros `00.50`, `007`. Leading-dot `.5` and `1.` are also accepted |
| `true` / `false` / `null` | common | Standard literals |

**Never seen in the corpus, but tolerated with a warning:** bare identifiers (read as strings), bare `nil` (read as null), single-quoted strings, duplicate keys (last wins), unknown string escapes. The corpus has **zero** duplicate keys and zero bare identifiers.

**Values that look special but are plain strings:**
- `"FLT_MAX"` is always quoted, e.g. `"beamDeform":"FLT_MAX"`.
- `nil` only appears inside `"$=…"` expression strings, e.g. `"$=$brakebias == nil and …"`.
- Expressions (`"$=…"`) can appear anywhere a value can, including flexbody **mesh names**.

Other facts:
- Files may start with a UTF-8 BOM.
- Line endings are mixed CRLF/LF.
- Filenames may contain spaces: `vehicles/covet/covet_bumper_R _midengine.jbeam`.

## Our implementation

`src/shared/jbeam/parse.ts` is a hand-written scanner with recursive descent.
- It preserves key order and reports syntax errors with line and column.
- `collectInfo` also records the benign quirks, which is how the table above was produced.
- `strict: true` rejects everything except comments. We use it to check our own output.

`src/shared/jbeam/serialize.ts` writes official-looking files:
- part keys flush-left, 4-space indent;
- one table row per line, with aligned columns;
- short flat dicts kept inline;
- `//` comments via `JbeamComment`.

The output is always **strict JSON plus comments**. Numbers never use exponents, and round-trips are exact.

### Tables (`src/shared/jbeam/tables.ts`)

```
"nodes": [
    ["id", "posX", "posY", "posZ"],          ← header: first array in the section
    {"group":"covet_hood"},                  ← option row: applies to all FOLLOWING rows (cumulative)
    ["h1rr", -0.72, -0.80, 0.865],
    ["h3", 0.0, -1.62, 0.775, {"nodeWeight":2}],  ← dict beyond the header = options for this row only
    {"group":""},                            ← reset by convention (empty value)
]
```

- Option dicts may appear **before** the header row. They apply from the first row.
- A dict *within* the declared columns is a value, not options. Example: `triggers2`'s `size` column holds `{"x":…}`.
- Rows may be **shorter** than the header (missing trailing columns are simply unset), or longer (extra values are kept).
- Official files contain misspelled header columns (`nonRLexMaterials` ×6, `rbonFlexMaterials` ×1). They also contain two `triangles` tables whose first row is data (`["0","5","8"]`). Treat headers as data, never as a fixed schema.

## Verification gate

`npm run jbeam:corpus` must report, per file:
- lenient parse → serialize → **strict** parse → deep-equal;
- the serializer is idempotent;
- `readTable` succeeds on every table-shaped section.

**Result on 0.39.1: 5062/5062 on all three checks. 68,286 tables were read.**

Re-run it after every BeamNG update. `docs/beamng-section-catalogue.md` is regenerated by the same run with `--catalogue=`.

## Not just .jbeam
- `info.json` (covet) has trailing commas, so `JSON.parse` fails on it.
- `.pc` files can have missing commas (`pickup/d15_4wd_A.pc`).
- Parse all BeamNG text with `parseJbeam`.
