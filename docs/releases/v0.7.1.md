# JBeam Forge 0.7.1 — mesh names and model export

## Downloads

- **JBeam-Forge-Setup-0.7.1.exe**: the installer.
- **JBeam-Forge-0.7.1-portable.exe**: a single exe with no install.

## New

**Meshes named after their parts**
- Assign a mesh to "Rear Left halfshaft" and it becomes `rear_left_halfshaft`. More meshes in the same part get `_2`, `_3` and so on, and split pieces get proper names too.
- In-game part names lose leftover numbers, so "Hood (2)" becomes "Hood".
- Rename any mesh yourself: right-click it in the Scene tree and choose **Rename…**. Names you type are never changed automatically, and everything can be undone.
- Already-assigned project? Right-click in the Scene tree (or press **Ctrl+K**) and run **Rename meshes from their parts**.
- Both automatic renames can be switched off in **Settings → Naming**.
- The original name is never lost. Hover a mesh in the tree to see it, and your source file is never touched.

**Export the model**
- **File → Export Model** writes your whole model back out with the new names, grouped by part:
  - **.glb** opens straight in Blender, with materials.
  - **.dae** is ready for BeamNG.
- The mod export uses the new names too.

**Split at the centre line**
- Right-click meshes that cover both sides of the car (a whole front suspension or both halfshafts in one object) and choose **Split at the centre line**. You get a left and a right piece in one step.

**Smarter part detection**
- When a mesh's name and where it actually sits disagree (a "Front-Left-rotor" placed at the rear right), its position wins, and it's flagged for you to check.
- Assetto Corsa "GEO_Cockpit"/"GEO_Details" meshes are no longer guessed, because they mean different things on different cars.

**Also**
- **Settings** is now in the File menu (**Ctrl+,**) as well as the gear icon.

## Fixed

- **Projects with FBX models saved in 0.6.0/0.7.0 opened with every mesh unassigned.** This was caused by 0.7.0 keeping Blender's `.001` names. Those projects now reopen with everything where it was. Save once to store the update.
