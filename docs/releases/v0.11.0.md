# JBeam Forge 0.11.0: settings in game, lights, glass, configurations and publishing

## Downloads

- **JBeam-Forge-Setup-0.11.0.exe**: the installer. The materials and objects packs are included.
- **JBeam-Forge-0.11.0-portable.exe**: a single exe, with both packs included.
- **JBeam-Forge-Materials-0.11.0.zip** / **JBeam-Forge-Objects-0.11.0.zip**: the packs on their own.

## New

**Hinge preview**
- The Hinges section draws the hinge line, the latch and the handles in the viewport.
- A swing slider opens the part so you can check it clears the body.

**Settings adjustable in game**
- Choose which part settings (mass, stiffness, strength) show up in the game's Tuning menu, with their range and default.
- They export as jbeam variables, so players can change them without editing files.

**Lights glow in game**
- Headlight, brake light, reverse, fog, indicator and light bar materials light up with the game's electrics.
- Each gets an "on" twin material, generated for you.

**Glass shatters**
- Glass parts break when hit: their flexbodies swap to a frosted, cracked material.

**Configurations** (the tree icon)
- Named versions of the car, such as Base, Sport or Race, each choosing a part for every slot. The parts are laid out like the game's parts menu.
- Set tuning values per configuration.
- **Preview** shows only the parts that configuration fits.
- Each exports as its own .pc file with an info file and a preview picture.

**Prepare for the repository** (Export → For the repository…)
- Fill in the listing: title, tagline, version, description and tags.
- A checklist shows what reviewers look for: validation, a preview for every configuration, author, description and version.
- Writes a folder with the mod zip, the pictures and the listing text (README.md and description.txt), ready to upload.

## Please try in-game

The tuning settings, lights, glass and extra configurations are all new to the export. Load each configuration once, flick the lights on, and hit something with glass. If anything errors, send me beamng.log.
