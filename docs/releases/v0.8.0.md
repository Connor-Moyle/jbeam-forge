# JBeam Forge 0.8.0 — materials

Materials are now part of your project, and you can edit them in depth.

## Downloads

- **JBeam-Forge-Setup-0.8.0.exe**: the installer.
- **JBeam-Forge-0.8.0-portable.exe**: a single exe with no install.

## New

**Everything comes in automatically**
- Import a model and every material and texture it uses becomes a project material. Older projects pick theirs up the first time the model loads.
- The mod export writes `main.materials.json` in the same format the stock BeamNG cars use, and copies the textures into the mod.

**The Materials panel** (switch to the Materials layout)
- Every material, with a colour swatch and how many meshes use it. Click a mesh to jump to its material.
- Edit everything BeamNG's material format supports:
  - Up to four layers, each with colour, metallic, roughness, opacity, normal strength, clear coat, glow colour and brightness.
  - Every texture slot: base colour, normal, metallic, roughness, AO, emissive, opacity, clear coat, paint mask and detail normal. Each slot has its own file picker and a second-UV switch.
  - Transparency and blend mode, alpha cut-out, double-sided, shadows, reflections, vertex colours, glow and anisotropic filtering.
  - **Raw fields** for anything else, merged into the output as-is.
- **Car paint:** switch a material to paint and it uses the player's paint colours in game.
- **BeamNG materials:** type the name of one of the game's own materials and your mod uses it directly.
- Changes show in the viewport straight away. Dragging a slider is one undo step.

**Library**
- **34 presets:** paints (gloss, metallic, pearl, matte, satin), chrome and other metals, plastics, rubber, carbon, clear and tinted glass, head/tail/indicator lenses, leather, fabric, alcantara, carpet and lamp glows.
- **Your own library:** save any material, and it's there in every project. Its textures are copied along, so it keeps working if the project moves.
- **Share materials** as `.jbmat` files, textures included.

**Tidying up**
- **Merge duplicates:** finds materials that are exact copies (`Aluminum-1` / `Aluminum-1.001` / `Chrome_02`…) and merges them in one go. Identical materials with different names are only suggested, never merged without you ticking them.
- **Drag and drop** a material onto a mesh in the viewport, or onto a mesh or part in the Scene tree.

## Known gaps

- Coming later: UV tools (island view, unwrap, projections), AO baking, and single-channel viewport views.
- The viewport preview is close to BeamNG's look, but not identical.
