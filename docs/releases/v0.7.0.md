# JBeam Forge 0.7.0 — editing and focus mode

This is the editing release. You can now shape the generated structure by hand, focus on one part at a time, and get around the app faster.

## Downloads

- **JBeam-Forge-Setup-0.7.0.exe**: the installer.
- **JBeam-Forge-0.7.0-portable.exe**: a single exe with no install.

Still unsigned, so SmartScreen will warn you. Click **More info → Run anyway**.

## New

**Editing nodes and beams**
- Press **Tab** (or use the pointer button in the toolbar) to edit the structure.
- **Selecting:** click a node or beam, or drag a box. Shift adds, Ctrl removes. **L** selects connected nodes, **I** inverts, **Ctrl+A** selects all, and double-clicking a node selects its whole part.
- **Moving:** use the gizmo (BeamNG axes: X left, Y rear, Z up) or the arrow keys, which nudge 5 mm (Shift 25 mm, Alt 1 mm). You can also type exact coordinates in the inspector.
- **Symmetry** is on by default, so moving a left node moves its right partner. **Soft-move** drags nearby nodes along with a smooth falloff.
- **Topology:** **B** connects the picked nodes with beams, **M** merges them, **D** splits beams in half, and **Delete** removes things.
- **Node details:** rename a node and every beam, triangle and reference node follows. Set weights on one node or many. Pick two nodes to see the distance between them.
- Regenerating a part now keeps the nodes you moved by hand.

**Focus mode**
- Double-click a part, press **F**, or click the focus icon in the tree. The part and everything attached to it stays solid, the rest of the car ghosts out, and the camera glides over.
- **Esc** leaves. You can set how see-through the ghost is in Settings → Viewport.
- **X-ray** (toolbar) makes the whole car see-through the same way.

**Getting around**
- **Ctrl+K command palette:** type a part name to jump to it, or run any action.
- **F1** shows every keyboard shortcut.
- The **jbeam panel** shows the exact file Export will write for the selected part, live as you edit.
- The status bar shows the **front/rear and left/right weight split**, and a marker in the viewport shows the centre of gravity.
- **Undo survives saving and reopening.** The history is stored next to the project file.

**Parts**
- The scene tree now groups parts by type: Doors → Front doors → Front left door, then Glass, Lights, Interior and so on.
- **Prices and weights are automatic.** They're based on every stock car and truck in the game, adjusted for the construction material. Type your own value to override, or click "reset to automatic".

**Import**
- Much better at models converted from other games or exported from Blender. Tested on a converted Sunburst FBX:
  - `light_FL` becomes a headlight and `window_R` the rear window.
  - Gas caps, dials, cockpit meshes and Italian seatbelt names are recognised.
  - Blender's `.001` copies stay part of the same piece.
- Uncompressed DDS textures now load.

## Known gaps

- Coming in a later update: camera bookmarks, snapping, scaling/rotating a selection, triangle editing, and per-node friction/material settings.
- Meshes with default names like `Circle.004` still need assigning by hand.
- Hinges, materials, suspension and engines are still on the roadmap.
