# JBeam Forge 0.13.2: a proper E30 practice car, and save files that always carry over

## Downloads

- **JBeam-Forge-Setup-0.13.2.exe**: the installer. It updates any earlier version in place; your settings, projects and library stay.
- **JBeam-Forge-0.13.2-portable.exe**: a single exe, nothing to install.

Projects are now format v20. 0.13.2 opens projects from every earlier version and brings them up to date; the first save keeps the original beside it (`name.jbforge.v19.bak`) so an older app can still open that copy. Earlier versions can't open projects saved by 0.13.2 and say so (update the app).

## New

**The practice car is a BMW E30 318i**, remodelled from scratch as an example of a well-built car model:
- Real E30 dimensions (4.33 m long, 1.645 m wide, 1.38 m high, 2.57 m wheelbase) and the details that make it one: the shark nose with the kidney grille and four round lamps in a black band, chrome bumpers with rubber strips and black end caps, the waist crease from nose to tail, thin pillars, the Hofmeister kink, a short flat boot with wide ribbed tail lamps, rubbing strips, door handles, cross-spoke wheels.
- Clean topology: every panel is its own grid of quads cut exactly on its shut lines, with edge loops round the wheel arches, along the crease and round the window frames. The OBJ keeps the quads, so it opens in Blender as a modeller would build it.
- Every panel is a thin shell with an inside and edges: take off a door, the bonnet or the boot lid and you see the cabin (with door cards), the engine bay or the boot, not a hole.

**Save files always carry over**: projects from every earlier version open in this one with their parts, structure, hinges, animated parts and triggers intact. Real projects saved by earlier versions are kept as test files, and the tests fail if a change to the project format ever comes without an upgrade step. See docs/releasing.md.

**Every release is the next version number**: the release build now refuses a version that isn't newer than the latest release, and never replaces one.
