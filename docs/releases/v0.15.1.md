# JBeam Forge 0.15.1: game suspensions front and rear

## Downloads

- **JBeam-Forge-Setup-0.15.1.exe**: the installer. It updates any earlier version in place; your settings, projects and library stay.
- **JBeam-Forge-0.15.1-portable.exe**: a single exe, nothing to install.

Projects stay format v21, so every 0.14 and 0.15 version opens them.

## Fixed

Found by fitting an ETK 800 front and rear suspension, inline-6 and 6-speed to the practice car and reading the export back the way the game does.

**Node names the game's wheels already use.** The firewall and rear window got nodes named like fw1l and rw1r, which is what the game's wheels call their hub nodes. With a game suspension fitted, the game saw those nodes twice. New structure uses fwal… and rwin… instead. A project generated before stops at export with the part to regenerate (Generate), so nothing broken reaches the game.

**The right wheels driven.** An axle is only driven when it brings its own differential. A suspension whose wheel shafts hang on a differential that stayed behind (the ETK 800's front on a rear-drive car, where the differential is an empty slot) used to get a centre differential sending 40 % of the torque to nothing. Now that axle rolls freely and the gearbox drives the rear through the car's own driveshaft, as on the stock car.
