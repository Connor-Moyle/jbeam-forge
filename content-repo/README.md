# JBeam Forge content

Materials, meshes and vehicle scripts for [JBeam Forge](https://github.com/Connor-Moyle/jbeam-forge),
the BeamNG.drive modding tool. You don't need to download anything from this page: open JBeam Forge,
press **Ctrl+Shift+D** (or Help → Downloads) and pick what you want. The app keeps it up to date.

| Folder | What's in it | In the app |
|---|---|---|
| `textures/` | materials: paints, metals, carbon, glass, fabrics, decals… | Downloads → Textures, then the Materials panel |
| `meshes/` | ready-made parts: calipers, discs, gauges, seats, suspension pieces… | Downloads → Meshes, then Add object |
| `scripts/` | vehicle scripts (Lua) to add to any car | Downloads → Scripts, then Settings → Scripts |

## Versions

Every change here is built into a new version automatically (the **downloads** branch, tagged
`v<date>.<build>`). The app downloads the newest one, only fetching what changed, and can go back
to any earlier version (Downloads → Version).

## Adding content

See [ADDING.md](ADDING.md). In short: put a folder in the right place, commit, and the rest is
automatic. Anyone can suggest content with a pull request; it's checked before it's merged.

## Licences

Each item's folder may hold its own `LICENSE` or `README.md` with its author and terms. Use items in
your mods according to those. Anything without its own licence is free to use in BeamNG.drive mods,
including paid ones, but not to re-sell on its own.
